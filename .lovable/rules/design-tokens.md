# Design Tokens

Token reference for **NES**. Use utility classes and CSS variables — never raw values.

## Colors

Reference via `var(--name)` in inline styles or CSS.

| CSS variable |
|---|
| `--nes-primary` |
| `--nes-primary-hover` |
| `--nes-success` |
| `--nes-success-hover` |
| `--nes-warning` |
| `--nes-warning-hover` |
| `--nes-error` |
| `--nes-error-hover` |
| `--nes-dark` |
| `--nes-bg` |
| `--nes-surface` |
| `--nes-hover` |
| `--nes-disabled` |
